# Gaon Health Help (Saathi Health Help) - CSE326 CA3

A web-based rural healthcare assistance portal designed for ASHA workers and village health volunteers to assist rural communities with basic health guidance, common ailment information, medicine recommendations with approximate pricing, and emergency hospital contacts.

## Features
- **Patient Call Log**: Register and track calls from patients needing assistance.
- **Common Health Problems**: Symptoms, recommended primary care medicines, and doctor consultation warnings for 15 common conditions.
- **Basic Medicines Directory**: Visual catalog with medicine photos, primary uses, and approximate market pricing.
- **Nearby Hospitals**: Contact information and distances for primary health centres, civil, and district hospitals.

## Tech Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## How to Run
Open `index.html` in any modern web browser.
